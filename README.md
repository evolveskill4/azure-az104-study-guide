## 📌 Exam Domain Weightage Breakdown

| Domain | Exam Weightage | Key Focus Areas |
| :--- | :--- | :--- |
| **Manage Azure Identities & Governance** | 20–25% | Microsoft Entra ID, RBAC Roles, Azure Policy, Subscriptions |
| **Implement & Manage Storage** | 15–20% | Storage Accounts, Blob Access Tiers, Azure Files, SAS Tokens |

## 🛠️ Practical Hands-on Lab Checklist

- [ ] **Lab 1: Identity & Access Control** — Set up Microsoft Entra ID users, custom RBAC role assignment, and conditional access policies.
- [ ] **Lab 2: Virtual Networking & Peering** — Build hub-spoke VNet topology, attach Network Security Groups (NSGs), and configure user-defined routes (UDR).
- [ ] **Lab 3: Azure Storage Security** — Configure lifecycle management rules, generate time-limited SAS tokens, and mount Azure Files over SMB.
- [ ] **Lab 4: Compute Deployment & Autoscaling** — Deploy Azure Virtual Machine Scale Sets (VMSS) with automated health probe metrics.
- [ ] **Lab 5: Disaster Recovery & Monitoring** — Configure Azure Recovery Services vault, implement daily VM snapshot policies, and set up Metric Alerts.
